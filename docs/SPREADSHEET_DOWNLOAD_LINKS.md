# Spreadsheet access from existing intent pages

For the genuine Excel/Spreadsheet P2 search intent, a single downloadable .xlsx is reused in the homepage calculator, the printable-cost guide, and the seller pricing guide. These links all point to the same versioned internal asset; no duplicate keyword landing page is generated.

Unlike a snapshot CSV, the file contains actual formulas and can be edited offline. The disclaimer is explicit: the spreadsheet starts with default sample values, it does **not** synchronize with the live browser form. CI verifies a real browser download on both guides, not just text matching.

The data remain 131 original terms: 25 P0 + 62 P1 active, 7 P2 deferred, 37 excluded. Current pages.dev remains intentionally noindex until a verified domain is purchased.
