# Design system

Product: PrintCost Studio. Market: US English, tool-first SEO. Users: FDM hobbyists and small print sellers. Primary journey: input slicer grams/time → read per-item cost → switch pricing/filament → optionally adjust order fees → copy/export/print.

Visual: light editorial workspace, not subscription marketing. Canvas #F6F8FC; surface #fff; body #344054; ink #101827; primary #1567E8; quiet rules #E4E9F2; rich navy result #14233C; positive #0F916D. System UI typography, tabular figures. 8px spacing rhythm, 12–17px radius. Desktop split roughly 60/40; below 930px stacked; below 620px compact mobile layout. Core controls and live outputs visible before long-form SEO content.

Motion: <200ms buttons/tabs and ~200ms cost bars, native CSS only; reduced-motion disables all. All input/labels/errors accessible via for/id and description references. No remote fonts/images. Hero and SVG brand are original; no competitor brand replicated. Real browser validation pending and marked NOT RUN.
